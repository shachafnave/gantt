# Security

Charts are static HTML files that run entirely in the browser. Plan data (task names, owners, logos) is embedded in the file and is treated as untrusted text when rendered.

If you find a way for plan content to run script, leak data, or otherwise misbehave, please report it privately through GitHub's "Report a vulnerability" button on the Security tab of this repository rather than in a public issue. You should hear back within a week.
